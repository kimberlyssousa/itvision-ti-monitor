## 📋 Sobre o Projeto

O **IT Vision** foi desenvolvido para simular uma plataforma corporativa de monitoramento e gestão de TI utilizada por equipes de:

- Service Desk
- NOC (Network Operations Center)
- Infraestrutura
- Suporte N2/N3
- Operações de TI

O objetivo é centralizar informações operacionais em uma única interface moderna e intuitiva.

## ✨ Funcionalidades

### 📊 Dashboard Executivo

- Indicadores de SLA
- Chamados abertos
- Equipamentos online/offline
- Alertas operacionais
- Gráficos em tempo real

### 🎫 Gestão de Chamados

- Abertura de chamados
- Acompanhamento de status
- Controle de prioridades
- SLA dos atendimentos
- Histórico de atendimento

### 🖥️ Inventário de Ativos

- Cadastro de equipamentos
- Controle de responsáveis
- Informações de rede
- Status operacional
- Dados de hardware

### 📡 Monitoramento

- Monitoramento de dispositivos
- Controle de disponibilidade
- Alertas operacionais
- Visualização centralizada

### 📚 Base de Conhecimento

- Artigos técnicos
- Procedimentos operacionais
- Documentação interna

## 🚀 Como Executar Localmente

```bash
git clone https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git

cd SEU-REPOSITORIO

npm install

npm run dev
```

## 🔐 Variáveis de Ambiente

Crie um arquivo `.env`:

```env
VITE_SUPABASE_URL=YOUR_SUPABASE_URL
VITE_SUPABASE_ANON_KEY=YOUR_SUPABASE_KEY
```
